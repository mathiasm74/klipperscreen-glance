The preheat screen. Direct manipulation beats +/- steppers: the left column is one horizontal temperature slider per heating element (Extruder, Heater bed, Chamber), each a 34px trough spanning that heater's real range (0–300° nozzle, 0–120° bed/chamber) with an amber fill up to the live temp, a white live-temp tick, and a cyan target handle you drag; scale ticks sit under each track. Drag snaps to 5°, releasing commits the target; the chamber row renders inert (grey tick, no handle) when no chamber heater exists. Only the active heater's live temp gets Anton (58px) — the others are 30px, targets are 22px cyan "target 240°" labels. Below the sliders, a 6-minute temperature history graph plots extruder (amber) and bed (white, 65% opacity) against dashed target lines with right-edge target labels.

Right column (296px, not the usual 45% side column — the sliders need the width): predefined material profiles as full-width 68px buttons, each showing the material name plus its "nozzle / bed" pair (PLA 215/60, PETG 240/85, ABS 255/100, TPU 230/45). One tap sets both targets and the profile fills solid cyan with dark bold text one size up. The stack bottoms out in Cool down (dim — sets all targets to 0) and a green-text "Hold at 240°" that keeps the current profile hot after a print. Phase color is amber throughout; the bottom rail shows heating progress toward the extruder target and reads 0% once at temperature.
