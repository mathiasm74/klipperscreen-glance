Glance color system. One phase color per screen — the machine state picks it (--ph-heat amber, --ph-prep cyan, --ph-print green, --ph-done violet, --ph-err red) and it paints the 5px screen frame, the Anton hero figure, and the bottom progress rail (solid fill on a 25%-alpha trough). Idle uses --dim. Surfaces stay near-black (--bg / --surface / --card / --sheet); text is --text with --dim labels. Selected controls: solid #33c5e8 fill, #0b0d10 bold text. Never introduce colors outside these tokens.
