The idle screen. Hero shows READY/WARM/HEATING as an 88px Anton word (white when idle, amber with a filling rail when heating), a dim status subline ("heaters off · homed") and a one-line temp readout. Side column is "Print again": one big recent-print card (thumbnail + name + duration) over two compact row cards, then a verb row (Preheat / Move / Filament / overflow). Tapping a card raises the start-confirm sheet: preview, name, duration, Cancel + Start — Start is green bold text on a dark button, not a green button.
