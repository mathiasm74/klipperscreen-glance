The job screen. Phase-colored frame + rail wrap the whole screen; hero column shows the phase word (dim, 26px), one huge Anton figure (percent while working, a word for PAUSED/DONE/error), and one subline ("1h 24m left · done 22:38"). The 45% side column carries the print thumbnail, filename, and state-dependent rows: temp rows while heating, Speed + Z-offset steppers while printing, Unload/Load while paused, Save Z when done — always capped by a row of 68px action buttons (pause/resume, stop, overflow). The Z-offset value marks its active digit with tiny arrows above/below it.
